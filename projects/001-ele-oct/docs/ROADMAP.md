# Project #001 — public roadmap

**Proposed schedule:** November 2–December 18, 2026. These dates are targets, not claims of completed work.

| Dates | Milestone | Exit criterion |
|---|---|---|
| Nov 2–6 | Baseline and startup audit | Reproducible token breakdown and 70K Hello baseline |
| Nov 7–13 | Memory schema and privacy boundaries | Versioned synthetic card, validation, namespace tests |
| Nov 14–20 | Context router | Bounded retrieval, provenance and deduplication tests |
| Nov 21–27 | Portable adapter prototype | One synthetic handoff across two model runtimes |
| Nov 28–Dec 4 | Outcome verification | Evidence-based completion and owner approval gates |
| Dec 5–11 | Benchmarks and hardening | Repeatable accuracy, latency and token comparisons |
| Dec 12–18 | Security review and release decision | Owner-approved public demo with documented limitations |

Success requires **verified outcomes per token**, not merely fewer tokens. Never expose real personal or production data to achieve a benchmark.
