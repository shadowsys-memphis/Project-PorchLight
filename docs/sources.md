# Sources

This file says where the public record comes from, and what stays off this repository.

## Google AI Studio

The app pages are a rewrite of a source review dated November 1, 2026. That review read 16 exported AI Studio projects. All 16 built with Vite. Fourteen rendered in a headless pass. Shadow.Ai AlphaRunner and FleetControl AI construct their model client at import time, so they did not render in that pass.

A seventeenth name, TradeOps Recovery Console, is known from a November 2025 description only. Its project was not in the export set, so its page is marked **Not reviewed**.

AI Studio "Updated" is a last-modified stamp. Six exports share a July 29–30, 2026 stamp that looks like a bulk re-save. App pages call a date approximate unless the source itself carries a better clue (a prompt date, a constitution timestamp, or dates written in the app).

The studio projects are not mirrored as source in this repo. Screenshots in [ai-studio-apps/screenshots/](ai-studio-apps/screenshots/) are the public frames from that review.
