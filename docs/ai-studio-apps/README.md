# AI Studio apps

Sixteen Google AI Studio exports, reviewed from source on November 1, 2026, plus one earlier project known only from its description. This index is the map. Each page separates the on-screen claim from what the source does, names the stack the review could see, and says what the artifact shows about the work.

The narrative timeline is the [creator profile](../creator-profile/README.md). Locations are in [sources](../sources.md).

## Status labels

| Label | Meaning in this set |
| --- | --- |
| Shipped | Running for a real user beyond the studio export. This index leaves the label unused. A later caregiving system is described as shipped and lives in the private BrainGuardian repo. |
| Prototype | Built and read from source. Behavior is partial, simulated, paper, or read-only. |
| Concept | A positioning piece or a client-style sketch. Roadmap, not a delivered product. |
| Not reviewed | Named from a description. Source was not in the export set. |

## How dates were read

AI Studio "Updated" is last modified. Six apps share a July 29–30, 2026 stamp that looks like a bulk re-save. Pages say **approximate** when that stamp is the only clock. Better clocks, used where the review found them:

- SovereignShadow Assistant: the system prompt states November 21, 2025.
- Sovereign Shadow II, AlphaRunner, and the Assistant: `@google/genai` 1.30.x and Gemini 2.5 / 3 Pro preview model ids, which place them in late 2025 or early 2026.
- SS_III: `constitution.json` field `created_utc` of 2026-02-16.
- Command Center & Auditor: April 15 and July 15, 2026, written in source.
- br(AI)n: 2026-05-21 written in source.
- Care Giver OS: June 22–July 6, 2026.
- Veteran Daily Routine Tracker: entries dated January 15–August 18, 2026.

## Review limits that apply to every page

All 16 exports built with Vite. KernelGuard needed a legacy peer-dependency install. AlphaRunner and FleetControl AI did not render headless, because their model client is created at import.

Market and portfolio figures on the screenshots are interface state. The review found those feeds simulated, paper, or, in iShadow, read-only. Balances, results, and keys stay out of the text.

Screenshots withheld on purpose: br(AI)n and Care Giver OS captures showed family and health context. They are not in [screenshots/](screenshots/).
